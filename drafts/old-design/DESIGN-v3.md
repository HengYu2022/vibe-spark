## 问题描述

Vibe Spark v1 收到真实用户反馈：评价「一般」。

反馈来自一个**零代码基础的 vibe coding 新人**，他当天刚开始用 Claude Code，但已经在做 AI 周报和 Crypto×AI 周报。他的评价：
- 灵感库里的 35 条灵感都是练手项目（番茄钟、贪吃蛇），对他没用
- 直接问 Claude Code 给方向，结果比跑 /vibe-spark 更好
- 但认可「给上下文 → 生成方向 + 第一步文档」这个机制本身有价值

核心洞察：**Vibe coding 新人 ≠ 编程新人。** 他们不需要练手，因为 AI 写代码。他们需要的是「值得做的方向，且跟我的背景相关」。

## 根因分析

v1 的错误假设：「不知道做什么」的用户需要一个菜单来挑。

实际情况：每个用户的背景不同，静态灵感库无法匹配。一个做 AI 周报的人看到番茄钟会觉得离谱。一个做 Crypto 的人看到贪吃蛇会关掉。

**静态库天然受限于覆盖面。AI 实时生成天然个性化。**

## v2 核心改变

从「灵感库」变成「灵感引擎」。

```
v1: 从库里挑  →  推 3 个  →  选一个  →  开工
v2: 了解你    →  为你生成 3 个专属方向  →  选一个  →  开工
```

| | v1 | v2 |
|---|---|---|
| 核心 | 静态灵感库匹配 | AI 实时个性化生成 |
| Phase 1 问什么 | 你想做什么类型？ | 你在做什么？想解决什么问题？ |
| Phase 2 怎么推 | 按标签从库里过滤 | AI 根据你的背景生成专属方向 |
| 灵感库角色 | 主菜单 | few-shot 示例（教 AI 什么是好灵感） + 保底 |
| 个性化程度 | 低（按标签） | 高（根据背景） |

## 前提

1. Vibe coding 新人 ≠ 编程新人，他们不需要练手项目
2. 每个用户的背景不同，静态库无法匹配所有人
3. AI 实时生成 + 用户背景 = 个性化灵感，这是静态库做不到的
4. 灵感库仍有价值：作为 few-shot 示例保证输出质量 + 让新人可以「逛」
5. 快速收敛仍然是核心原则（2-3 轮内锁定方向）

## v2 工作流

```
/vibe-spark

═══ Phase 0：环境感知（不变）═══
  读取持久化数据 + 检测项目上下文 + 更新检查

═══ Phase 1：了解你（核心改变）═══

  不再问「你想做什么类型的项目」
  
  【冷启动】
  问：「你最近在做什么？在什么领域工作或学习？」
  （单次提问，自由输入为主。也提供快捷选项：
   学生/自由职业/上班族/创业/纯粹好奇）
  
  然后追问一句：
  「有没有什么日常的痛点或重复劳动，一直想自动化但没动手？」
  
  【热启动】
  接过话头：「你上次做了 XXX，后来怎么样了？想继续还是换方向？」
  如果换方向 → 同冷启动流程

═══ Phase 2：灵感引擎（核心改变）═══

  1. 从灵感库读取 3-5 条作为 few-shot 示例
     （不是给用户看的，是教 AI 什么是好灵感的格式和标准）
  
  2. 根据 Phase 1 收集的用户背景，AI 实时生成 3 个专属方向
     每个方向包含：
     - 项目名称
     - 一句话介绍
     - wow factor（为什么这个方向值得做）
     - 跟用户背景的关联（为什么适合你）
     - 预估难度和时间
  
  3. 展示 3 个方向（卡片格式）
     + 第 4 个选项「我有自己的想法」
     + 第 5 个选项「换几个」
  
  4. 用户也可以说「我想浏览灵感库」→ 退回到 v1 的库浏览模式

═══ Phase 3：锁定 + 细化 ═══

  选了一个方向后，AI 进一步细化：
  - 核心功能 3-5 条
  - 推荐技术栈
  - 具体的第一步
  
  确认后输出文档。

═══ Phase 4：持久化（不变）═══
```

## 灵感库的新角色

灵感库不再是给用户看的主菜单，而是三个用途：

1. **Few-shot 示例** — 放在 SKILL.md 的 prompt 上下文里，教 AI 什么样的灵感是好的（有 wow、有第一步、有扩展方向）
2. **保底** — 如果 AI 生成的质量不好，或者用户说「我就想看看库里有什么」，可以退回到库浏览模式
3. **质量标杆** — 新的灵感库应该包含「有真实产品价值」的灵感（不只是练手），作为 AI 生成时的参考标准

## 灵感库内容升级

现有 35 条练手灵感保留，但补充一批「产品级」灵感作为 few-shot 示例的升级版：

```
练手级（现有）：番茄钟、贪吃蛇、Emoji 密码锁
  → 适合纯粹想找乐子的人

产品级（新增）：
  → 帮自由职业者自动生成发票的 CLI
  → 把微信/Slack 聊天记录变成结构化会议纪要
  → 监控所有 side project API 状态的仪表盘
  → 自动从 20 个信源抓取行业要闻生成日报
  → GitHub star 趋势分析器（哪些 repo 在涨？为什么？）
```

## 对那个用户的回答

如果 v2 做完，那个做 AI 周报的零代码用户再用 /vibe-spark：

```
Phase 1：「你最近在做什么？」
→ 「AI 周报和 Crypto×AI 周报」

Phase 2：AI 生成 3 个专属方向：
  1. Crypto 情报聚合器 — 自动从 20 个信源抓取要闻，生成你的 Crypto 日报
  2. 周报模板引擎 — 把你的周报流程产品化，让别人也能一键生成
  3. Token 用量看板 — 可视化你每天各个 AI 工具的花费和效率
```

这三个方向都跟他正在做的事直接相关。不是番茄钟。这就是「优秀」。
