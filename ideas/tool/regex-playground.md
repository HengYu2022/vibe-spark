## 一句话

交互式正则表达式学习工具，关卡制，从入门到精通。

## 为什么值得做

正则是每个程序员迟早要学的技能，但学习曲线陡峭。做成关卡制游戏化学习，既帮自己复习，又是一个有教育价值的开源项目。regex101.com 很好用但不够好玩。

## 核心功能

1. 关卡式学习（每关一个正则概念 + 练习题）
2. 实时匹配高亮（输入正则，目标文本中的匹配部分实时变色）
3. 正则可视化分解（把 `/\d{3}-\d{4}/` 拆解为人话）

## 第一步

用 Vite + React 初始化。做一个双栏布局：左边显示目标文本（高亮需要匹配的部分），右边是正则输入框。用 JavaScript 的 `RegExp` 对象实时匹配，`String.replace` 给匹配部分包上 `<mark>` 标签。硬编码 5 个关卡（字面匹配 → 字符类 → 量词 → 分组 → 前瞻）。

## 扩展方向

- 30+ 关卡覆盖完整正则语法
- 挑战模式：限时写出匹配目标的正则
- 社区关卡：用户自己设计关卡
